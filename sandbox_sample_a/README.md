# Proyecto: Validador de Correos Electrónicos

## Descripción
Este proyecto contiene un módulo `email_validator.py` que implementa una función para validar direcciones de correo electrónico y pruebas correspondientes en `test_email_validator.py`.

## Hitos Completados
1. Implementación del módulo `email_validator.py`
2. Creación de pruebas unitarias en `test_email_validator.py`
3. Ejecución exitosa de las pruebas
